13 / CALCULATE

직접 계산해 봅시다

200 × 130
200 × 130
160 × 112

01겹친 면적 160 × 112 = 17,920

02각 박스 면적 200 × 130 = 26,000

03합집합 26,000 + 26,000 − 17,920 = 34,080

04IoU 17,920 / 34,080 ≈ 0.53

문턱 0.50 → 통과같은 박스문턱 0.75 → 탈락
4분 합집합에서 겹친 면적을 한 번 빼는 이유를 질문한 뒤 계산합니다. IoU는 측정값이고 판정은 문턱이 만든다는 결론으로 마무리합니다.

MOCK DUEL · 012분 상의 + 3분 답변

IoU를 계산하고 판정하라

예측 박스와 정답 박스의 면적은 각각 400, 겹친 면적은 240이다.

  1. IoU를 계산하라.
  2. 정답 문턱이 0.5일 때 통과 여부를 말하라.
  3. 이 숫자만으로 신뢰도 score의 적절성도 판단할 수 있는가?
IoU = 240 / (400 + 400 − 240) = 240 / 560 ≈ 0.43 → 탈락

IoU는 정답 박스와의 위치 겹침, score는 모델 내부 적합도이므로 이 정보만으로 score의 적절성까지 판단할 수 없습니다.

모의대결 답변자는 계산식 → 판정 → score와 IoU의 차이 순서로 말하면 깔끔합니다.
