# 찾아내기와 경계 긋기

AI 에이전트 과정 섹션 3의 60분 인터랙티브 발표자료입니다.

## 구성

- 객체 탐지와 분류의 차이
- YOLO의 핵심 아이디어와 공통 구조
- 탐지 출력(label, box, score)과 업무 decision
- IoU 계산과 신뢰도 임계값 정책
- 시맨틱·인스턴스·파놉틱 분할
- 마스크 지표와 경계 정의서
- 쪽집게 예상문제 5개와 모의대결 3문제
- 모든 슬라이드의 발표자 노트

## 발표 조작

- `←` `→` 또는 `Space`: 슬라이드 이동
- `O`: 전체 슬라이드 보기
- `N`: 발표자 노트
- 우측 상단 `↗`: 전체 화면

GitHub Pages용 정적 발표자료는 `docs/`에 있습니다.
